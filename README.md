# Gym Management System

A full-stack web application for **FitCore Gym** designed to connect administrators, personal trainers, and gym members on a single platform[cite: 1].

## Overview

The system provides role-based access for three distinct user types[cite: 1]:

* **Administrators:** Manage members, trainers, and training programmes, assign trainers to members, and view system user lists[cite: 1].
* **Personal Trainers:** View assigned members and create or manage workout plans and specific exercise tasks[cite: 1].
* **Gym Members:** Access their assigned training programme, view workout plans, and track or update their exercise task progress (`Not Started`, `In Progress`, `Complete`)[cite: 1].

## Tech Stack

* **Frontend:** React with React-Bootstrap[cite: 1]
* **Backend:** ASP.NET Core 8 Web API[cite: 1]
* **Database & ORM:** Microsoft SQL Server with Entity Framework Core (Code-First)[cite: 1]
* **Security:** ASP.NET Identity (Role-based authentication & authorization)[cite: 1]
